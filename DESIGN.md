# BetterBacacay Design System

## 1. Purpose

BetterBacacay is a community-driven civic portal for Bacacay, Albay under the BetterGov / BetterLGU ecosystem.

The visual identity should feel:

- Local, not generic
- Civic, but not bureaucratic
- Warm and community-oriented
- Coastal and island-inspired
- Modern and digital-first
- Rooted in Bacacay's karagumoy weaving tradition
- Simple enough to be implemented consistently across pages

The site should not look like a generic government template, SaaS dashboard, tourism agency template, or AI-generated landing page.

---

# 2. Core Visual Concept

The design language is based on four Bacacay-specific ideas:

1. **Sea and channels**  
   Inspired by Bacacay's coastline, island communities, Cagraray Island, and Sula Channel.

2. **Island silhouettes**  
   Rounded, layered landforms representing Bacacay's island and coastal geography.

3. **Karagumoy weaving**  
   The most important cultural pattern in the interface. The woven motif should appear subtly throughout the site as a recognizable BetterBacacay design signature.

4. **Warm optimism**  
   Gold accents and sun-inspired highlights communicate progress, community, and a better future.

The interface should combine these ideas through soft wave-shaped section separators, woven background motifs, coastal imagery, and warm accent colors.

# 4. Logo Usage

The BetterBacacay logo combines:

- Island forms
- Sea / channel shapes
- Karagumoy-inspired woven bands
- A warm sun

The logo should normally appear in the header with the wordmark:

**BetterBacacay**

Optional supporting line:

**Our People. Our Home. A Brighter Bacacay.**

## Logo spacing

Keep clear space around the symbol equal to roughly 20–25% of its width.

Do not:

- Place the logo inside a heavy badge
- Add a circular border around it
- Apply drop shadows
- Add gradients to the logo
- Add glow effects
- Stretch or distort it

# 6. Typography

Use a clean modern sans-serif.

Recommended:

- Inter
- Geist
- Manrope
- Plus Jakarta Sans
- DM Sans

Primary headings should be bold, compact, and confident.

Example:

> Your community guide to Bacacay.

Heading characteristics:

- Weight: 700–800
- Tight but readable tracking
- Large size
- Avoid overly narrow display fonts

Body text:

- Weight: 400–500
- Comfortable line height
- Maximum readable width around 600–720px

## Script Accent

The mockup uses handwritten text for emotional/local phrases such as:

- Bacacay para sa lahat.
- Our Home. Our People. A Brighter Bacacay.
- Tradition Lives Here.

This should be used very sparingly.

Use the script style only for:

- One accent phrase per major section
- Tourism/cultural callouts
- Footer signature

Do not use script fonts for:

- Navigation
- Buttons
- Cards
- Government information
- Body copy

# 11. Wave Design Language

Wave shapes are one of the primary recurring BetterBacacay design elements.

They should be used for:

- Hero section transitions
- CTA bands
- Footer top edges
- Tourism sections
- Large section separators

## Wave style

Use broad, calm, smooth curves.

The wave should feel inspired by:

- Shorelines
- Island channels
- Calm coastal water

Avoid sharp zigzags or exaggerated cartoon waves.

Use 2–3 layers at most.

Example:

1. White foreground curve
2. Pale aqua curve underneath
3. Deep teal section background below

The curves should be asymmetrical enough to feel natural.

# 12. Karagumoy Woven Pattern

This is a critical part of the BetterBacacay identity.

AI-generated designs may miss this unless explicitly implemented.

The woven pattern should represent traditional **karagumoy weaving**.

## Pattern Construction

Use repeating diagonal bands forming a simple woven lattice.

Basic geometry:

- One set of diagonal lines leaning `/`
- Another set leaning `\`
- Alternating over-under intersections
- Slightly rectangular strip widths
- Large enough to be recognizable as weaving
- Not a tiny generic crosshatch texture

The pattern should resemble interlaced woven strips, not:

- Plaid
- Carbon fiber
- Checkerboard
- Tribal tattoo
- Herringbone flooring
- Random diagonal stripes

## Recommended implementation

Use:

- SVG pattern
- CSS background pattern
- Repeating inline SVG
- Low-opacity background image

Preferred opacity:

`3%–9%`

The woven pattern should remain subtle.

---

# 13. Where the Woven Pattern Should Appear

The pattern should not cover the entire website.

Use it strategically.

## A. Hero Transition

Place a very light woven pattern near:

- Lower-right edge
- Behind the wave transition
- Partially cropped off-screen

Use pale teal.

Opacity:

`4%–7%`

---

## B. Large Section Backgrounds

Use the pattern near the outer edge of sections.

Example:

- Right edge of Services section
- Left edge of Tourism section
- Behind large CTA panels

Never place it directly behind dense text.

# 26. Footer — Exact Design Direction

The footer is a major BetterBacacay brand element.

It should feel like the sea meeting the woven cultural identity.

## Overall Footer Shape

The footer should NOT start with a straight horizontal edge.

Use a large curved wave at the top.

Example:

- White content section above
- Curved deep-teal wave rising slightly at left
- Lower at center
- Rising again toward right

Add a second darker or lighter wave layer inside the footer for depth.

Keep curves calm and smooth.

`#DDE8EC`

`1px solid`

- Contrast

# 40. Accessibility

Minimum:

- WCAG AA color contrast
- Keyboard accessible navigation
- Visible focus states
- Proper heading hierarchy
- Alt text for images
- Semantic buttons and links
- Icons should not be the only label
- Do not communicate meaning only through color

---

- Helpful

- Respectful

# 42. Anti-AI-Slop Rules

Do not generate unnecessary UI such as:

- "Live now"
- "Active residents"
- Fake user avatars
- Random sparkles
- AI chat bubbles
- Fake analytics
- Infinite floating badges
- Startup-style testimonials
- Generic "Trusted by 10,000+" sections
- Fake awards
- Fake tourism ratings
- Fake live activity
- Overlapping floating cards
- Decorative statistics without real data

Every visual element should have a purpose.

The site should prioritize:

- Public information
- Services

- Barangay resources
- Community participation
- Accessibility
- Open-source friendliness

BetterBacacay should not visually imitate another BetterLGU portal exactly.

Its distinctive identity should come from:

**Sea + islands + karagumoy weaving + community.**

# 47. Design Signature

A user should be able to recognize a BetterBacacay page even when the logo is not visible.

This recognition should come from:

- Deep teal coastal palette
- Warm karagumoy gold
- Broad wave-shaped section edges
- Subtle woven strip patterns
- Strong local photography
- Teal uppercase section labels
- Small gold accent lines
- Clean civic card layouts

The woven motif and wave motif should be treated as the two primary decorative assets of the design system.

---

# 48. Final Design Principle

BetterBacacay should feel like a digital extension of Bacacay itself:

**woven by tradition, connected by the sea, and built for the community.**

The design must remain useful before it becomes decorative.

Every page should prioritize:

1. Clarity
2. Local identity
3. Accessibility
4. Trust
5. Community usefulness
